SHADOW MONSTERS SURVIVAL
Juego web original de supervivencia con combate automático, niveles, mejoras, orbes, jefe y controles táctiles.

PARA JUGAR:
Abre index.html en un navegador moderno.

PARA PUBLICAR EN GITHUB PAGES DESDE IPHONE:
1. Descarga ShadowMonstersSurvival.zip y descomprímelo en la app Archivos.
2. En tu repositorio de GitHub, entra en Add file > Upload files.
3. Sube index.html a la raíz del repositorio (reemplaza el archivo existente solo si quieres sustituir tu juego actual).
4. Pulsa Commit changes.
5. En Settings > Pages, selecciona la rama main y /(root), guarda y abre el enlace de GitHub Pages.

Este prototipo es un juego independiente inspirado en el género survivor; no usa Pokémon ni recursos oficiales de PokeSurvivor.
